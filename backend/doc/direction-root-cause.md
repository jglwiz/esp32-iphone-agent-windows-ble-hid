- “接收绝对目标”不等于“底层绝对定位”：旧 visual_relative 仍靠相对步进、增益估计和截图迭代，增加了误差及状态来源。现删除整个控制器，不只改默认名称。

- “新帧”和“报告已发送”不是效果确认：frame_time 是 PC 接收发布时刻，可能仍显示手机之前的状态；按钮回执也不证明命中。保留连续响应门禁及人工看图，失败不回退、不重复提交未知结果。
- “校准文件存在”不代表可用：旧记录为描述符 v1、当前设备 v3，运行态 needs_verification。保留连接、描述符、几何和校准有效性检查，不改文件字段冒充重新验收。校准只修正稳定小偏差，不修复丢失响应或方向反转。

保留必要的状态管理：连接身份、输入释放义务、请求去重、校准有效性；不保存未经观察的“真实位置”。定位失败停止，未来实机验收未通过就不宣称绝对 API 鲁棒。
