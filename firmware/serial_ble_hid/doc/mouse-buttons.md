# 原地点击的按钮报告（0.4.1）

0.3.3 在当前 iPhone 上出现移动有效、`mouse.click` 已提交却不触发界面的情况。Safari 对照中，相对移动后点击与原生移动后相对点击均没有 pointerdown/up；原生定点点击出现可信触控事件。“自定义更多按钮”也未识别到 Report 2 点击。辅助触控主开关原本开启。尚未证明某个唯一的 iOS 缓存或描述符缺陷是根因，本地 notify 成功不代表手机输入成功。

## 报告与语义

| Report | BLE value | 职责 |
| --- | --- | --- |
| 1 | 8 字节 | 键盘 |
| 2 | 4 字节：padding、相对 X/Y、滚轮 | 相对移动与滚动，不承载按钮 |
| 4 | 5 字节：padding、16 位绝对 X/Y | 原生定位，不承载按钮 |
| 5 | 1 字节：三个按钮位及 padding | 唯一按钮状态，不包含坐标 |

Report ID 存在 Report Reference 中，不放进 BLE value。两个运动集合保持独立；把两套 X/Y 放在同一 Mouse 集合的 v2 原型在实机移动回归中失败，未采用。正式 descriptor version 为 3，Backend 接受 1/3，并将校准绑定实际版本，旧配置不能自动沿用。

`mouse.click` 只向 Report 5 发送按下、等待 60ms、松开，不调用定位函数、不读取 last_commanded_x/y。`mouse.down/up` 同样使用 Report 5。`abs.click` 保留显式定位，但按钮通过同一报告发送。会话释放、取消与租约过期只释放按钮和键盘，不发送缓存绝对坐标。通知错误时保留释放义务，未知结果不重放。

## 升级与证据

设备广播名为 **S3-Click-Buttons**，使用根据板子 MAC 确定的独立静态随机身份，隔离旧 HID 缓存。升级旧版需要配对新名称，不自动删除旧配对。已实测候选与正式版保留相同身份、名称和 Report Map，正式部署无需再配对。后端仍以硬件 device_id 绑定板子。

状态的 `button_subscribed`、`click_report_id=5`、`click_repositions_pointer=false` 和诊断的 `button_reference_hex=0501` 只表示外设能力与路由，实际生效仍须观察手机。

2026-11-02 候选独立 `click()` 五例通过，包含相对移动后点击、三个安全位置及等待 10 秒后点击。每例只有一个 trusted pointerdown/up/click，无 cancel；通过四个独立标记将 DOM 落点映射回截图，与主代理审查的可见指针中心误差均小于 2px。没有用 `click_at()` 代替。

正式源码编译并单写 app0 后，已有配对自动恢复，descriptor=3、button reference=0501，取帧 PID 保持。正式入口三例再次通过：两个不同实际位置及等待 10 秒后点击，误差分别约 0.13/0.28/0.43px。正式布局测试 `../tests/test_reports.py` 三项、完整 Backend 128 项均通过，无跳过；这些数量不等于跨设备或长期压力验收。

上述误差是事件映射点与人工填写的可见指针中心之差；目测中心保留约 5px 观测不确定度，不能将小数结果当成亚像素硬件精度。

2026-11-03 原生界面收尾通过：用户返回主屏并恢复 AirPlay 后，纯相对移动将可见指针放到首页“搜索”控件内部，主代理独立审图确认约 (245,883)。仅提交一次 `click`（request_id `6bbc2bc9bb7546bf803e8a9352b0ae0f`，不含坐标或移动），实际打开 iOS 搜索页和键盘，输入框为空。主代理查看完整动作前后原图通过；未输入或发送内容。累计为八例页面事件验收及一次系统界面点击。

收尾时 Backend 空闲无故障，设备已连接，各 HID 通道 ready。临时事件观察器已停止。取帧进程仍为原进程；本轮未重启接收器，但跨夜 UxPlay PID 已变化，不能声称始终是同一接收进程。截图在本地实验目录 `trial/home-final/`。

## 未解决的移动方向

当前连接观察到约 90 度旋转：原生目标 (180,480) 实际约 (275,392)，(320,620) 实际约 (211,698)；相对两个轴都有正交位移。一次保留配对的设备复位后仍然存在，不能归结为丢弃 padding，也没有反向拟合来放行。

`click()` 的当前位置语义独立验证；这不代表 `move_to` / `click_at` 任意目标定位已通过。坐标门禁保持，定位异常时停止。拖拽、滚轮、其他按钮、跨设备和长期稳定性不因本轮点击通过视为完成。

原始截图、事件及备份在本地忽略 Git 的 `tasks/relative-click/lab/button-report/`；正式代码与运行时不依赖实验目录。
